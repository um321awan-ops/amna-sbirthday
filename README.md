# A Day for You

A cheerful, mobile-responsive four-page birthday greeting for Amna, with a burgundy-and-rose glassmorphism look, original Urdu birthday poetry, a CSS-illustrated cake, candle interactions, floating hearts and stars, birthday wishes, and a personal letter.

## Run locally

1. Install Node.js (18+ recommended).
2. In this folder, run `npm install` if dependencies are not already installed.
3. Run `npm run dev` and open the local address Vite prints.
4. Run `npm run build` to create a production build in `dist/`.

## Make it personal

Edit the birthday copy and Urdu verses in `src/main.ts` to add your own memories and personal sign-off. The cake and all decorations are drawn with CSS, so no image assets are needed.
